# ToDo App — Интерактивный менеджер задач

Веб-приложение для управления персональным списком дел, разработанное с акцентом на архитектуру компонентов и удобный пользовательский интерфейс. Проект демонстрирует навыки работы с состоянием (State Management) и браузерным хранилищем данных.

## 🚀 Основной функционал
*   **Управление задачами (CRUD):** создание, отметка о выполнении, редактирование и удаление задач в реальном времени.
*   **Фильтрация контента:** удобная сортировка списка по статусам (Все / Активные / Завершенные).
*   **Data Persistence:** автоматическая синхронизация с `LocalStorage` — данные сохраняются после перезагрузки страницы.
*   **Счетчик прогресса:** динамическое отображение количества активных задач.
*   **Адаптивный дизайн:** интерфейс корректно отображается на десктопах, планшетах и смартфонах.

## 🛠 Технологический стек
*   **Библиотека:** React (Hooks: `useState`, `useEffect`)
*   **Язык:** JavaScript (ES6+)
*   **Стилизация:** CSS3 (Flexbox, Grid)
*   **Хранение данных:** Web Storage API (LocalStorage)
*   **Инструменты:** Git, GitHub, npm

## 🏗 Аналитическая и техническая работа
В рамках реализации проекта были выполнены следующие задачи:
1.  **Проектирование логики:** разработан алгоритм жизненного цикла задачи от создания до архивации.
2.  **Архитектура компонентов:** структура проекта разделена на логические блоки для обеспечения масштабируемости и чистоты кода.
3.  **Оптимизация UX:** внедрена фильтрация без перезагрузки страниц и мгновенная валидация пустого ввода.
4.  **Data Management:** реализован слой взаимодействия с `LocalStorage` для имитации работы с базой данных на стороне клиента.
