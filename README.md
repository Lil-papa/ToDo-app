ToDo App — Интерактивный планировщик задач
Веб-приложение для управления персональными задачами, разработанное с акцентом на чистую архитектуру компонентов и удобный пользовательский интерфейс.
🚀 Функционал
CRUD операции: создание, чтение, обновление статуса и удаление задач в реальном времени.
Фильтрация: удобная сортировка списка (Все / Активные / Завершенные).
Persistence (Хранение данных): автоматическое сохранение списка в LocalStorage — ваши задачи не пропадут после перезагрузки страницы.
Интерактивный UI: динамический счетчик оставшихся задач и адаптивная верстка для мобильных устройств.
🛠 Стек технологий
Core: React (Hooks: useState, useEffect)
Language: JavaScript (ES6+)
Styling: CSS3 (Flexbox, Grid)
Version Control: Git & GitHub
📋 Реализация (Analytical & Technical approach)
В ходе разработки проекта были решены следующие задачи:
Проектирование логики состояния: Реализован однонаправленный поток данных для обеспечения предсказуемости поведения интерфейса.
Оптимизация UX: Внедрена мгновенная валидация ввода и фильтрация без задержек.
Data Management: Настроена работа с браузерным хранилищем для имитации бэкенд-составляющей (Persistence layer).
